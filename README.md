# Snigdha Mishra | Portfolio

Personal portfolio built with plain HTML, CSS and JavaScript (no frameworks, no site builders).

**Live site:** https://snigdha4413.github.io

## Pages
- `index.html`: about, projects carousel, community roles, hobby flip cards, skills, contact
- `project.html`: detail page for each project (content lives in `projects.js`)
- `community.html`: community photo slideshow and roles

## How it works
- `art.js` paints the card and slide artwork on `<canvas>`, draws the scroll-driven ribbon, and builds the shared nav.
- `projects.js` holds the project text, so it is the one file to edit when a project changes.
- `style.css` holds all styling and the mobile layout.
